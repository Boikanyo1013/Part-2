## Description
QuickChat App - Part 1 Login & Part 2 Message features

## How to Run
1. Download zip
2. Extract
3. Open in NetBeans / IntelliJ
4. Run PROG5121_FA1.java for full program (login + messages)
5. Run RunMessagesOnly.java for messages only
6. Run Tests: Right-click Project > Test

## Features
- Username validation (_ and <=5 chars)
- Password validation (8 chars, cap, number, special)
- Cell +27 format validation
- Recipient number validation (+ and <=13 chars)
- Message ID generation (10 digits)
- Message Hash creation
- Message length check (<=250)
- Sent/Stored/Disregard options
- JSON storage
